  1. 剧本名一杯苦酒取自俄文书籍《一杯苦酒》，作者在此书中详述了那个牢不可破的国家从诞生、发展直至消亡的历程。书名为一杯苦酒，即回顾此中历史犹如在品味一杯苦酒，如作者所言，此书是他“多年来思考、怀疑、踌躇和苦恼的结果”。剧本背景设计在一个平行世界的架空历史（Alternative History），聚焦在一个国家行将分离的末期，不同的人做出不同的选择，进而将国家引入不同的结局——捍卫当下，故步自封，大厦终倾亦或是涅槃重生，一切取决于玩家的选择与努力。剧本选取了最具有博弈性与紧张感的黯月风格，毒醉与生死的交织则暗合剧本名“一杯苦酒”。因此，角色不只是实际的角色，也是一种境遇性的暗喻：就善良角色而言，赌徒代表着那些激进的改革派，杂技演员代表着领导者平衡各方如走钢丝，疗养师代表着国家有待治疗却看不到前路，只能先拖着醉汉的躯体苟延残喘，而盖棺人则可能是对国家命运的最后断言……红色方也有着自身的计谋，无论是尸妖构陷忠良扰其心智，还是刺客直接出手斩首行动，种种设计使得红蓝两方针锋相对，在未知的舞台上一决雌雄。 四个恶魔的胜利对应了国家的不同结局：僵怖代表着建制派拒绝改革，通过更极端的控制（场 活 一 人）维持旧貌，蚀疫魔意味着国家在自然灾害推波下彻底崩坏，珀是少部分精英在隐忍中巧取政坛，别西卜是国家在贪婪的榨取式制度下竭泽而渔又轰然坠地。然而，每种负面结局都有其正面的对应：疗养师可能使社会在修生养息后重回正道，游歌者可能是人民在风雨中的精神港湾，盖棺人可能只是在平安时期对短暂紧急状态的一个回望，甚至，赌徒可能也是以雷霆之手段，迅速终止了一场潜在的危机。一切尽在，这一杯苦酒中。 “让这一杯远离我吧，但不要照我的意思，而要照你的意思。”

  2. 一杯苦酒的定位是一个黯月风剧本。这从该剧本有4个导致处决不死的角色，4种不同刀数的恶魔与大量导致额外死亡的非恶魔角色便可见一斑。然而，与黯月不同的是，在这个剧本中，生死与中毒醉酒更加紧密地联系在一起：疗养师使得该剧本对处决不死这一事实的解读多了一个层次：处决不死的玩家可能中毒或醉酒了，尽管处决不死的角色稍少，但可能导致处决不死的原因却异常丰富：店小二与游歌者导致的醉酒，盖棺人的酒不醉人人自醉，蚀疫魔与尸妖的位置毒……疗养师的设计使无痕的毒醉有了有形的代言人。配合茶艺师的阵营不死逻辑，形成了一个紧密交织的网络。杂技演员同样如此，尽管是一个外来者，但是在剧本环境中却常常处于风暴中心：无论是与店小二互动证出三个好人，还是与盖棺人互动为邪恶盖上灵柩，亦或是使尸妖无所遁形……剧本的设置使得杂技演员死亡时的解读空间颇为丰富——虽然，也可能只是一个意外死亡的史莱姆。究其原因，是剧本设计使得毒酒在这个剧本中不只是简单干扰人的状态，也是一种“沉默的信息”，正如生死在黯月不只是轮次的推进，也展露出了信息的一面一样。让染更多的状态展现出自己的另一面，这是剧本在运作方面的设计宗旨。 为了适应生死与毒醉交杂的风格，设计了疗养师，盖棺人两个角色，他们都或多或少与这个主题相联系：疗养师是生死与毒醉沟通的桥梁；盖棺人则直接联系了毒醉与检测——如果得知了铁好人，那么可以推测此时没有邪恶玩家死亡，即使盖棺人不能信任自己的信息，被得知的善良玩家也可以通过盖棺人的状态得知邪恶势力仍然猖獗。 在毒醉生死这一体现“酒”的明线之外，“后悔”则是剧本“苦”的暗线。别西卜是一个快刀恶魔，理论的每晚双刀给了玩家紧张感，但是也鼓励了玩家私聊与换皮，尤其是鼓励了外来者隐藏自身：如果别西卜在意外中选择了外来者往往会给自身带来轮次上的亏损。另外一个有趣的点是，作为一个邪恶角色，别西卜却希望外来者越少越好（如果外来者未达到善良玩家的一半），这使得其与云栖客有了奇妙的缘分。 同时，为了适应剧本中复杂的毒酒环境，也为了解决黯月在少数情况下容易坐牢的难题，为所有玩家创造了私货商人狄奥尼索斯。狄奥尼索斯是希腊神话中的酒神，在尼采眼中，狄奥尼索斯所代表的酒神精神与阿波罗所代表的日神精神相对，指的是在狂醉的状态中忘却生命痛苦、与自然相交融的精神。在本剧本中，则希望玩家借助狄奥尼索斯所提供的各种酒品，不只是反制毒醉，更是能从毒醉中寻求到胜利的道路。狄奥尼索斯提供五种“酒品”：解控的蛋酒，反伤的公牛子弹，赌狗专属的月光蜜酿，有数酒家美称的苦艾酒，以及说走就走的盘尼西林。他们功能多样却又适应剧本角色互动，使得剧本在毒醉生死交杂的环境中创造了全新的博弈空间。玩家能不能喝对酒，喝好酒，成为了红蓝对抗的重要一环：既可能巫师学徒巧用蛋酒捉邪恶，也可能魔女尸妖苦艾将那僵怖藏。即使是相同的角色配置，由于玩家酒品饮用策略的不同，也可能有着完全不同的展开。为了增加酒品的策略深度，并减少说书人在给出酒品时的思考量，所有的酒品在有正面的同时有其负面：公牛子弹和苦艾酒可能加速游戏的进行，蛋酒可能使得蓝酒牌（侍臣、享乐主义者、吟游诗人）失去作用，盘尼西林会使得玩家不能行动，月光蜜酿则本身就是赌狗专享。在实际游玩中，甚至出现过一个晚上好人全部死于酒品的“盛况”，究竟是解忧杜康还是一杯苦酒，尽在玩家的推杯换盏之中。也推荐在线下酒吧游玩该剧本，可以搭配真实酒品进行游玩。（不过记得把头孢换成糖果x）

  3. 店小二

    在你的首个夜晚，你会得知两名善良玩家。他们之中会有一人醉酒，即使你已死亡。

    ““客官您里边儿请嘿！是打尖儿呐还是住店啊？””

    店小二对他店里的顾客非常熟悉，但也为某些酒量不高的顾客感到焦虑。

    Examples

    ·店小二得知了赌徒和巫师学徒这两名玩家，其中赌徒因为他而醉酒。

    How to Run

    在为首个夜晚做准备时，分别将“熟客”和“醉酒”提示标记放置到两名善良玩家的角色标记旁。从现在起，标记了“醉酒”的那名善良玩家会醉酒直到游戏结束（或店小二离场）。 在首个夜晚，唤醒店小二。分别指向标记了“熟客”和“醉酒”的这两名玩家。然后让店小二重新入睡。

    （在考虑店小二的能力让谁醉酒时，你应该优先选择获取信息类的角色。这是因为非获取信息类的角色的醉酒状态要么非常容易确认（如守夜人），要么非常难确认（如士兵）。同时，让获取信息的角色醉酒，可以确保即使玩家已经找到了店小二让谁醉酒之后，醉酒依然能产生一定的效果。）

    ·在首个夜晚，店小二会得知两名玩家，这两名玩家都属于善良阵营。

    ·店小二所得知的两名玩家之中，会有一名玩家始终醉酒，即使店小二已经死亡。

    ·如果店小二在游戏中途被创造，他会在当晚得知两名玩家，且他得知的这两名玩家之中会有一名玩家醉酒。

    ·如果已经死亡的玩家变成了店小二，他不会得知任何信息，但仍然会让一名善良玩家醉酒。

  4. 赌徒

    每个夜晚*，你要选择一名玩家并猜测该玩家的角色：如果你猜错了，你会死亡。

    ““正面，我赢。反面，你输。””

    赌徒能够猜测玩家的角色……但是猜错的代价是相当巨大的。

    Examples

    ·赌徒指向吟游诗人玩家，然后指向吟游诗人图标。本次猜测正确，因此赌徒依然存活，但是当晚他还是被恶魔杀死了。

    ·魔鬼代言人正试图伪装成疗养师。当晚，赌徒指向魔鬼代言人玩家，然后指向疗养师图标。本次猜测错误，因此赌徒死亡。

    How to Run

    除了首个夜晚以外的每个夜晚，唤醒赌徒。让赌徒指向任意一名玩家，然后指向角色列表上的任意一个角色图标。让赌徒重新入睡。如果所选的玩家的角色和所选角色图标不同，赌徒死亡——将“死亡”提示标记放置到赌徒的角色标记旁。

    ·除了首个夜晚以外的每个夜晚，赌徒需要选择一名玩家，并在角色列表上指向一个角色图标来猜测其角色。如果猜测正确，无事发生。如果猜测错误，赌徒死亡。

    ·赌徒不会从说书人处得知自己的猜测是正确还是错误。

    ·赌徒可以选择任何玩家，无论是已死亡还是存活，甚至可以是赌徒自己。

  5. 追猎者

    每个夜晚*，你可以选择一名玩家：如果与他邻近的两名玩家阵营不同，且他不是恶魔，他死亡。

    “"不是所有人都跟动物那么聪明，也不是所有动物都和某些人那么笨！"”

    追猎者循着邪恶的踪迹击杀玩家。

    Examples

    ·黑星是追猎者，雪淞和讷之与圆头耄耋相邻，其中雪淞是善良的，讷之是邪恶的，圆头耄耋是邪恶的爪牙，黑星选择了圆头耄耋，由于圆头耄耋两侧的玩家阵营不同，圆头耄耋死亡了。

    ·小熊是追猎者，荣神是珀，尘叔和蓝与荣神相邻，其中尘叔是邪恶的，蓝是善良的，小熊选择了荣神，由于荣神是恶魔，无事发生。

    ·提线政客是追猎者，与灰烬相邻的卷饼和阿西都是邪恶的，提线政客选择了灰烬，由于灰烬两侧的玩家阵营相同，无事发生。

    How to Run

    在除了首个夜晚以外的夜晚，唤醒追猎者，让他进行选择一名玩家。如果与那名玩家相邻的两名玩家阵营不同，他死亡。将追猎者的“死亡”提示标记放置在那个玩家的角色标记旁。

    •从第二晚开始，唤醒追猎者选择玩家，如果被他选择的玩家两侧邻近的玩家阵营不同，则被追猎者选择的玩家会死亡。

    •追猎者选择的玩家是否会死亡与其本身的阵营无关，只与被选择的玩家邻近玩家的阵营有关，且不跳过死亡的玩家。

    •恶魔不会死于追猎者的能力。

  6. 驱魔人

    每个夜晚*，你要选择一名玩家（与上个夜晚不同）：如果你选中了恶魔，他会得知你的角色，但他当晚不会因其自身能力而被唤醒。

    ““每一个不洁之灵，每一份撒旦之力，每一次炼狱敌人的猛袭，每一个军团，每一个崇拜恶魔的组织和教派，以我主耶稣基督的名义和力量，将你们驱逐。我命令你们，远离上帝的教堂，远离上帝按祂的形貌所创造并受神圣羔羊的宝血所救赎的灵魂。””

    驱魔人能阻止恶魔被唤醒来发动攻击。

    Examples

    ·驱魔人选择了别西卜。别西卜当晚不会杀人。在黎明，说书人宣布当晚无人死亡。

    ·珀选择不攻击任何人。在下一个夜晚，驱魔人选择了珀。珀当晚不会被唤醒进行攻击。再下一个夜晚，驱魔人选择了刺客。刺客仍然可以在当晚发动攻击，并且珀选择攻击三名玩家，因为珀在上次选择时（两天前）没有选择任何玩家。

    ·驱魔人选择了蚀疫魔。蚀疫魔当晚不会被唤醒来发动攻击，但是因为蚀疫魔中毒的玩家仍然中毒。

    How to Run

    除了首个夜晚以外的每个夜晚，唤醒驱魔人。让驱魔人指向任意一名玩家。（如果驱魔人指向上一夜选择过的玩家，摇头表示否定，并让他指向另一名玩家。）将“被选择”提示标记放置到所选玩家的角色标记旁。让驱魔人重新入睡。

    如果驱魔人选择了恶魔，唤醒恶魔。向恶魔展示“该角色的能力对你生效”信息标记以及驱魔人角色标记，然后指向驱魔人玩家。并让恶魔重新入睡。当晚的后续时段中，不要因为恶魔的自身能力唤醒恶魔。

    （被驱魔人选中的恶魔不会被唤醒来使用自己的能力，但是如果有需要的话，仍然会因其他角色的能力被再次唤醒，如忏悔者。）

    ·除首个夜晚以外的每个夜晚，驱魔人都需要选择一名玩家。如果所选玩家不是恶魔，恶魔仍然可以发动攻击。如果选中了恶魔，恶魔当晚不会被唤醒，因而当晚不会选择玩家进行攻击。恶魔会得知他不能发动攻击，且得知谁是驱魔人。

    ·任何其他恶魔能力仍然会生效——例如僵怖被杀后依然保持存活，普卡会杀死他在上一个夜晚攻击的玩家，或是沙巴洛斯反刍一名玩家。

    ·驱魔人不能连续两个夜晚选择同一名玩家。

  7. 游歌者

    每个白天，你可以公开选择任意名存活玩家：当晚其中的镇民玩家会醉酒直到下个黄昏，你会被唤醒得知当晚因你醉酒的人数。

    “"吟游十数载，诗酒趁年华"”

    游歌者每个白天可以选择任意名玩家：其中的镇民都会醉酒，当晚你可以通过其中醉酒的玩家数量得知其中有多少名镇民。

    Examples

    •沫沫是游歌者，沫沫在白天公开选择了5名玩家，其中只有鸭鸭一人是镇民，鸭鸭会从当天黄昏开始醉酒到下一个黄昏，当晚沫沫得知“1”，代表1名玩家因为他醉酒。

    •沫沫是游歌者，沫沫在白天选择了鸭鸭一名玩家，尽管鸭鸭是镇民但鸭鸭饮用了月光蜜酿恢复了清醒，当晚沫沫得知“0”，因为没有玩家因为他的能力醉酒。

    •沫沫是游歌者，沫沫在白天选择了鸭鸭一名玩家，鸭鸭是镇民且饮用了蛋酒，当晚沫沫仍然得知“1”，因为鸭鸭仍然因为他的能力醉酒。

    •沫沫是游歌者，沫沫在白天选择了鸭鸭一名玩家，鸭鸭是镇民且鸭鸭同时因为侍臣的能力醉酒，当晚沫沫得知“1”，因为鸭鸭仍然因为他的能力醉酒。

    How to Run

    在白天的任意阶段，游歌者可以公开选择任意名玩家。游歌者选择以后，在他选择的镇民玩家旁放置“醉酒”标记，这些玩家从黄昏开始醉酒到下一个黄昏，夜晚时唤醒游歌者，并告知他场上的“醉酒”标记数量。

    •被游歌者选择的镇民玩家会从当晚醉酒至下个黄昏，而游歌者可以通过醉酒的玩家数量得知其中有多少名玩家是镇民。

    •如果游歌者选择了自己，他会醉酒到下个黄昏且不会让其他玩家醉酒，夜晚时你可以告知他错误信息（如果他饮用了蛋酒，这种情况只可能会得知1）。

    •如果游歌者选择的镇民饮用了月光蜜酿，那么他不能因为游歌者的能力醉酒，自然不会使游歌者的信息+1。

    •相反，如果被游歌者选择的镇民饮用了蛋酒，只是那名镇民的能力正常生效，但他仍然因为游歌者的能力醉酒，因此会让游歌者的信息+1。

    •虽然游歌者只能选择存活玩家，但是被游歌者选择的镇民即使在当晚死亡了也仍然醉酒，且仍然会让游歌者的信息+1。

  8. 巫师学徒

    每个夜晚*，你要选择一名玩家：你会得知除你以外的通过自身能力影响或在夜晚选择过他的角色中有哪些角色类型。

    ““我从他的身上感受到了邪恶的气息。””

    Examples

  9. 盖棺人

    每个夜晚*，你会得知一名邪恶玩家。你醉酒，除非有邪恶玩家死亡。

    ““最后一杯，明晚有活了……””

  10. 疗养师

    一名玩家醉酒。中毒或醉酒的玩家不会死亡，每个夜晚*，你会得知是否有玩家因为你避免了死亡（从上个黎明到你被唤醒时）。

    ““睡吧，孩子。””

    疗养师照顾那些中毒或醉酒的小镇居民，让他们免于死亡。然而，安宁的环境让一些居民开始沉醉……

    Examples

    ·圆头耄耋是疗养师，提线政客因为尸妖的能力中毒了，然后提线政客被处决，但他没有死亡，因为他被圆头耄耋的能力保护了，当晚唤醒圆头耄耋告诉他“是”。

    ·灰烬是疗养师，提线政客上个夜晚被魔鬼代言人选择，且因为疗养师的能力醉酒了，然后提线政客在今天被处决却没有死亡，当晚唤醒灰烬告知他“否”，因为提线政客被魔鬼代言人选择，本来就不会死亡，没有因为疗养师的能力避免死亡。

    ·卷饼是赌徒，他因为疗养师的能力醉酒了。卷饼赌了提线政客是史莱姆，然而提线政客是云栖客，但因为卷饼醉酒并没有死亡，但疗养师得知“否”，因为卷饼在首夜就醉酒了，本来就不会死亡，没有在今天因为疗养师的能力避免死亡。

    How to Run

    在首个夜晚，将疗养师的“醉酒”标记摆放在任意一名玩家的角色标记旁。当疗养师离场或死亡时，移除疗养师的“醉酒”标记。

    当有玩家本应在今天死亡，却因为疗养师的能力没有死亡时，在疗养师的角色标记旁放置“护理”标记，当晚唤醒疗养师告诉他“是”，然后移除“护理”标记，否则告诉“否”。

    •疗养师会保护那些醉酒或中毒的玩家不会死亡，这包括处决引起的死亡，无论玩家的角色或阵营。

    •多数时候建议疗养师的能力让一个镇民醉酒。但是如果局势合适，借此保护外来者，爪牙甚至恶魔存活得更久，或减少邪恶玩家被怀疑的程度，也是被允许的，毕竟死亡的疗养师不会再让玩家醉酒。

    •别让疗养师因为自己的能力醉酒，真别吧。

    •如果一名中毒或醉酒的玩家本来已经因为其他角色的能力不会死亡（例如与茶艺师相邻的善良玩家，被魔鬼代言人选择的玩家），不会将此视为由疗养师避免的死亡。

    •如果一名玩家本来拥有让自身死亡的能力，但因为疗养师的能力醉酒了，他失去那种能力且不会因为这种能力死亡，这不算作他今日因为疗养师避免了死亡，因为疗养师的醉酒是在首夜造成的，他那个时候就失去能力了。

  11. 马车邮差

  12. 侍臣

    每局游戏限一次，在夜晚时，你可以选择一个角色：如果该角色在场，一个该角色从当晚开始醉酒三天三夜。

    ““比起一只羊带领的一百头狮子，我更害怕一头狮子带领的一百只羊。””

    侍臣能使一个角色醉酒，且不需要知道该角色是哪名玩家。

    Examples

    ·已经过去了四个夜晚，侍臣都被唤醒但没有使用自己的能力。在第五个夜晚，侍臣使别西卜醉酒。从今晚起的三个夜晚，别西卜能够行动，但是无法杀死任何人。

    ·侍臣在醉酒时使用了自己的能力。无事发生，但侍臣再也不会被唤醒了。

    ·侍臣使魔鬼代言人醉酒。被魔鬼代言人选择的珀被处决而魔鬼代言人依然存活。游戏结束，善良阵营获胜。

    How to Run

    每个夜晚，唤醒侍臣。侍臣要么摇头表示不使用能力，要么指向角色列表上的任意一个角色图标。让侍臣重新入睡。

    如果侍臣使用了能力且该角色在场，对应的玩家当晚醉酒，持续三天三夜。将侍臣的“醉酒1”放置到该玩家的角色标记旁。在下一夜，将“醉酒1”替换成“醉酒2”。再下一夜，将“醉酒2”替换成“醉酒3”。再下一夜的黄昏，移除“醉酒3”，且侍臣失去能力。将“失去能力”提示标记放置到侍臣角色标记旁，并从夜晚顺序表上移除其夜晚标记。

    在侍臣选择了角色使其醉酒后，在本局游戏的剩余时段内不再唤醒侍臣。

    ·每局游戏限一次，侍臣可以选择一个角色，使其醉酒三个夜晚和三个白天，立即生效。

    ·侍臣不会得知自己成功或失败，因此侍臣可能会选到不在场的角色。

    ·侍臣选择的是一个角色，而不是一名玩家。说书人可能需要提醒侍臣玩家注意这一点。也需要提醒试图伪装成侍臣的邪恶玩家注意这一点。

    ·如果醉酒或中毒的侍臣选择了一个角色，该角色不会醉酒，即使侍臣于之后恢复了清醒和健康。如果侍臣使一个角色醉酒，但是侍臣变得醉酒或中毒，那名醉酒的玩家会重新恢复清醒。如果侍臣在三个夜晚和三个白天结束前又恢复了清醒和健康，那名被侍臣选中角色的玩家还是会继续醉酒。

  13. 茶艺师

    如果与你邻近的两名存活的玩家是善良的，他们不会死亡。

    ““若你感到寒冷，茶能使你温暖。 若你感到愤怒，茶能使你冷静。 若你感到沮丧，茶能使你振奋。 若你感到激动，茶能使你镇定。””

    茶艺师保护着她邻近的玩家免于死亡……只要他们都是善良的。

    Examples

    茶艺师在游戏开始时的邻近玩家是刺客和杂技演员。刺客被处决且死亡。现在，茶艺师邻近的存活玩家是杂技演员和侍臣。恶魔攻击了侍臣，但侍臣依然存活。

    How to Run

    如果茶艺师邻近的两名存活玩家都是善良的，将茶艺师的“不会死亡”提示标记放置到这两名玩家的角色标记旁。如果茶艺师邻近的两名存活玩家中有任何一个是邪恶的，移除这些提示标记。根据这个条件在整局游戏中随时更新这些提示标记（例如一名玩家的阵营改变了）。

    如果一名标有“不会死亡”的玩家将要死去，该玩家依然存活。如果一名标有“不会死亡”的玩家被处决，宣布该玩家被处决但依然存活。（不要说明原因。）

    ·如果茶艺师邻近的两名存活玩家当前都是善良的，这两名玩家就都不会死亡。恶魔不能杀死他们，教父和造谣者也不行。如果他们被处决，也不会死亡。唯一的例外是刺客，他能杀死受到保护而免于死亡的人。

    ·茶艺师的邻近的存活玩家是最靠近茶艺师两名存活玩家——一名为顺时针方向最近的存活玩家，一名为逆时针方向上最近的存活玩家。已死亡的邻近玩家会被跳过。

    ·然而，如果邻近的存活玩家其中之一是邪恶的，或者两个都是邪恶的，那么茶艺师就无法保护她的邻近存活玩家。如果一名邪恶玩家死亡，使得茶艺师现在的两个邻近玩家都是善良的，那么他们就又都不会死亡了。

    ·茶艺师的“不会死亡”标记仅做提示作用，仅仅只是被挂上这个标记不算作被茶艺师影响。只有当玩家因为茶艺师的能力免于死亡时，才算做被茶艺师的能力影响，从而被巫师学徒查验出“镇民”。

  14. 享乐主义者

    与你相邻的存活玩家（不计算旅行者）醉酒。

    ““芜湖！””

    享乐主义者让他邻近的存活玩家醉酒：无论是镇民，外来者，爪牙甚至恶魔。

    Examples

    ·享乐主义者饮用了蛋酒，当晚，享乐主义者旁边的僵怖被刺客杀死，僵怖进入假活状态且不再因为享乐主义者的能力醉酒，因为他在享乐主义者眼中是死亡的。然而，如果侍臣此时选择了僵怖，僵怖又会因为享乐主义者的能力醉酒，因为此时僵怖在享乐主义者眼中是存活的，而且在三天后，僵怖仍然因为享乐主义者的能力醉酒，因为僵怖因为享乐主义者的能力醉酒，他就被享乐主义者视为存活的，就能因为享乐主义者的能力醉酒（参考诺-达鲺与士兵，诺-达鲺不能让士兵中毒，然而如果士兵因为投毒者的能力中毒，他就会因为诺-达鲺的能力中毒，且投毒者选择其他玩家后，士兵仍然因为诺-达鲺的能力中毒，因为此时他已经失去了免收恶魔侵害的能力）。

    How to Run

    在游戏的首个夜晚，在享乐主义者相邻玩家的角色标记旁放置享乐主义者的“醉酒”标记。

    当其中任意玩家死亡后，将享乐主义者的“醉酒”标记立刻移动到该方向上下一个存活非旅行者玩家旁。

    •如果享乐主义者相邻的玩家死亡，将享乐主义者的“醉酒”标记移动到该方向上下一个邻近的存活玩家。

    •享乐主义者的能力与角色类型无关，即使是恶魔也会因为享乐主义者的能力醉酒。

    •享乐主义者的能力是实时监测的。

    •如果一名玩家的能力在死亡时触发（如忏悔者），在享乐主义者旁死亡则无法触发，因为享乐主义者的醉酒是在被醉酒的玩家死亡后解除的。

    •如果魔女在享乐主义者旁死亡，不再因为享乐主义者醉酒，且能够正常使用自己的能力，你可以理解为魔女的能力只是要求他在死后使用，并不是在死亡时获得。

  15. 吟游诗人

    当一名爪牙死于处决时，除了你和旅行者以外的所有其他玩家醉酒直到明天黄昏。

    ““我应倾听，当你轻敲我心…… 美梦因你，甜美温馨…… 若你羞赧，难以决定…… 我会安睡，待你光临。””

    如果有爪牙因为处决而死去，吟游诗人会让所有人醉酒。

    Examples

    ·刺客被处决，因此吟游诗人让所有人醉酒。在下一个白天，教父被处决，因此吟游诗人让所有人再次醉酒。恶魔两个夜晚都没办法成功发起攻击。

    How to Run

    当僵怖首次死亡后，他依然存活。宣布僵怖已经死亡，但是不要在魔典中给僵怖添加帷幕标记。（如常将城镇广场上他的生命标记翻面。）从现在起，僵怖被当作已死亡。

    除了首个夜晚以外的每个夜晚，如果没有玩家标有“死于今日”，唤醒僵怖。让僵怖指向任意一名玩家。让僵怖重新入睡。所选玩家死亡——将“死亡”提示标记放置到该玩家的角色标记旁。

    ·看似死亡的僵怖在绝大多数情况下都算作已死亡。该玩家在城镇广场的生命标记会翻面以标识死亡。下一次该玩家投票时，会失去投票标记。该玩家不能发起提名，该玩家可以在有巫毒师的情况下投票，该玩家不算作茶艺师的存活邻近玩家，等等。不同之处是游戏还会继续，僵怖仍然能发起攻击，且游戏会在只剩两名其他存活玩家的情况下继续进行。

    ·如果无人在白天死亡，僵怖才会在夜晚被唤醒并发起攻击。如果一名已死亡的玩家被处决，该玩家无法再次死亡，因此僵怖仍然会被唤醒。

  26. 珀

    每个夜晚*，你可以选择一名玩家：他死亡。如果你上次选择时没有选择任何玩家，当晚你要选择三名玩家：他们死亡。

    ·在第二个夜晚，珀攻击了一名玩家。在第三个夜晚，珀选择不攻击任何人。在第四个夜晚，珀攻击了三名玩家。

    ·如同其他的恶魔，珀可以在每晚攻击一名玩家。然而，如果珀不选择任何人，那么在下个夜晚珀可以攻击三名玩家。 ·如果珀在上一个夜晚不选择任何人时处于醉酒或中毒，当晚珀仍然能够选择三名玩家。 ·当要求珀选择三名玩家时，他必须要选择。珀不能再次不选择任何人。 只有当珀不选择任何人，才能得到三次攻击的机会。如果珀在上一次进行选择时攻击了某人但该玩家没有死亡，珀也不会获得三次攻击的机会。 ·珀在首个夜晚不行动，但这不算作珀“没有选择”。 ·如果驱魔人选择了珀，珀不会行动，但是这并不算作珀“没有选择任何人”。然而，如果珀在驱魔人选择他的前一夜就没有选择任何人，那么在驱魔人选择珀的下一夜，珀能够选择三名玩家，因为珀在上一次选择时没有选择任何人。

  29. 狄奥尼索斯：酒神

    见其它酒品

  30. 蛋酒：庆典

    中毒或醉酒不会影响你和存活邪恶玩家的能力使用，直到下个黎明。邪恶玩家不能主动饮用蛋酒。

    ““Happy, Lucky, Smile!””

    如果一名玩家饮用了蛋酒，他的能力会在下个黎明前正常生效，即使他中毒或醉酒。

    Examples

    ·盖棺人索要到了蛋酒，今天，刺客死于处决，吟游诗人在场，其它玩家都醉酒了。然而，当晚恶魔仍然正常造成杀戮，盖棺人得知了正确信息，因为他们都免受中毒醉酒影响；然而，下个白天，被魔鬼代言人选择的马车邮差仍然死于处决了，因为蛋酒的效果只持续到下个黎明而不是下个黄昏。

    ·盖棺人索要了蛋酒，场上还没有邪恶玩家死亡，当晚，盖棺人旁边的杂技演员死亡了，因为蛋酒只是让盖棺人免受中毒和醉酒的影响，但并不会他因为自身能力造成的醉酒。

    ·疗养师索要了蛋酒，当晚，侍臣醉了刺客，恶魔杀死了疗养师，刺客选择了侍臣，侍臣没有被刺客杀死，因为蛋酒的效果随着疗养师死亡失效了。

    How to Run

    如果说书人给予了一名玩家蛋酒，在他的角色标记旁放置“蛋酒”酒品标记，在全部存活邪恶玩家的角色标记旁放置“庆典”提示标记：这些玩家的能力在当晚的效果不受中毒或醉酒的影响。下个黎明到来时，或饮用蛋酒的玩家死亡时，撤去这些标记。

    •邪恶玩家不能主动饮用蛋酒，但是只要有玩家饮用了蛋酒，他们便会分享到蛋酒的效果，且不占用他们引用酒品的次数。

    •蛋酒并不会去除一名玩家醉酒或中毒的状态，只能保证他的能力各部分都正常发动，这意味着他们依然能够与疗养师、杂技演员等毒醉相关的角色互动。

    •如果在线下，不需要倒置已经存在的中毒或醉酒标记。

    •如果盖棺人喝了蛋酒，他在当晚一定会获得一个邪恶角色；如果有玩家喝了蛋酒，被侍臣醉酒的恶魔也能杀死玩家……然而，他们仍然会保持自己醉酒或中毒的状态。

    •如果饮用蛋酒的玩家都死亡了，邪恶玩家也会失去蛋酒的庇护。例如，刺客被侍臣醉了，恶魔杀死了当晚唯一饮用蛋酒的善良玩家，则刺客仍然不能让造成死亡。

    •在游戏进行到中期乃至后期，蛋酒会更容易缺货。一局游戏建议给出0-2杯蛋酒。一般情况下，不要在游戏的第一个白天给盖棺人蛋酒。

  31. 公牛子弹：决斗

    从这个黄昏开始，直到下个黎明，让你中毒或醉酒的玩家会在当晚死亡，如果他是恶魔，则你代替他死亡。

    ““午时已到！””

    如果一名玩家饮用了公牛子弹，那么让他醉酒或中毒的玩家会在当晚死亡。然而，如果那名玩家是恶魔，饮下公牛子弹的玩家会自己死亡。

    Examples

    ·还没有邪恶玩家死亡，盖棺人喝了公牛子弹，游歌者选择了盖棺人。当晚，游歌者死亡了，因为公牛子弹生效前，盖棺人都因为游歌者的能力醉酒，而不能让自己醉酒，所以盖棺人没有死亡，之后，盖棺人醉酒。

    ·游歌者、疗养师让侍臣醉酒，蚀疫魔让侍臣中毒，当天侍臣饮用了公牛子弹，游歌者、疗养师和侍臣死亡了，其中游歌者和疗养师让侍臣醉酒故死亡，侍臣因为恶魔蚀疫魔的能力中毒了故死亡。

    How to Run

    如果一名玩家饮用了公牛子弹，在他的角色标记旁放置“公牛子弹”酒品标记。当晚，如果饮用公牛子弹的角色标记旁出现了中毒或醉酒标记，立刻在这些中毒和醉酒的能力来源的角色标记旁放置公牛子弹的“决斗”提示标记，在公牛子弹生效时，将非恶魔玩家角色标记旁的“决斗”标记都替换为公牛子弹的“死亡”标记，如果恶魔玩家的角色标记旁有“决斗标记”，在对应饮用公牛子弹的玩家角色标记旁放置公牛子弹的“死亡”标记。如果饮用公牛子弹的玩家死亡，撤去“公牛子弹”和“决斗”标记。在黎明时，宣布有公牛子弹“死亡”标记的玩家死亡，并撤去剩余公牛子弹相关标记（如果有的话）。

    •饮用公牛子弹的玩家会杀死在当晚让自己醉酒或中毒过的非恶魔玩家，这发生在玩家角色造成的死亡之后，这意味着，在这个剧本中的绝大部分已经中毒或醉酒角色不会因为公牛子弹而在当晚获得正常发动的能力。

    •然而，公牛子弹仍然是强大的：对于善良玩家而言，这可以确认一些宣称可以让他人醉酒或中毒的善良玩家是否是真实的；对于邪恶而言，这可以阻止一些可怕的阻碍——例如，反杀可怕的侍臣！然而，请注意公牛子弹造成的死亡可以被保护类角色（如茶艺师，疗养师）所防止。

    •只要一名非恶魔玩家的能力在当晚让饮用公牛子弹的玩家中毒或醉酒了，无论该中毒或醉酒在什么时候开始的，也无论该中毒或醉酒是否在公牛子弹生效前终止，这名非恶魔玩家就会死亡。 •如果造成的饮用公牛子弹的玩家中毒或醉酒的玩家里有恶魔，则饮用者会代替恶魔死亡。

    •公牛子弹的能力是回溯的，这意味着只要从服用公牛子弹的那个黄昏到公牛子弹造成死亡的时间中有任何一刻饮用公牛子弹的玩家醉酒，造成饮用公牛子弹的玩家醉酒或中毒的玩家都会在公牛子弹生效的那一刻死亡。

    •如果有多名玩家让你醉酒或中毒，他们都死亡，顺序由说书人决定。

    •如果一名玩家因为自身能力让自己中毒或醉酒，饮用公牛子弹也会让自己死亡；此外，如果造成饮用公牛子弹的玩家中毒或醉酒的玩家是恶魔，饮用公牛子弹的玩家也会死亡。如果公牛子弹杀死的多名玩家中包括饮用者，建议最后让公牛子弹的饮用者死亡。

    •公牛子弹不算罕见，容易获取，但需要用牛肉高汤现场调配，一局游戏建议给出0-2杯公牛子弹，其中一个阵营0-1杯。

  32. 月光蜜酿：烈！

    你立刻醉酒。如果你因为其它原因醉酒或中毒，你清醒健康。

    ““请勿将葡萄砖按特定比例溶于水中并于阴凉处静置！””

    月光（Moonshine）在禁酒令期间被指代私酿的高度烈酒——劲大！

    Examples

    ·盖棺人索要了月光蜜酿：由于此时没有邪恶玩家死亡，他因为自身能力醉酒，故因为月光蜜酿保持清醒健康。然而，当晚，魔女死亡，盖棺人不再因为自身能力醉酒，因而因为月光蜜酿醉酒了。

  33. 苦艾酒：调制

    ·如果当天没有发生任何处决，屠夫无法在当天使用自己的角色能力。
